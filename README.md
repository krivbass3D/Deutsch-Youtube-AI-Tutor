## 🚀 Быстрый старт (3 минуты)

### 1. Установите зависимости
```bash
npm install
```

### 2. Создайте файл `.env`
```bash
GEMINI_API_KEY=ваш_api_ключ
```
[Получить API ключ →](https://aistudio.google.com/)

### 3. Запустите приложение
```bash
npm run dev
```

### 4. Откройте в браузере
```
http://localhost:3000
```

**Готово! Приложение запущено! 🎉**

## 🔧 Решение проблем

### Уроки не сохраняются?
1. Откройте консоль (F12)
2. Проверьте логи - что пишется?
3. Проверьте cookies (должны быть включены)

### ИИ не отвечает?
1. Проверьте `.env` - есть ли API ключ?
2. Проверьте консоль на ошибки
3. Убедитесь что ключ рабочий

**[TESTING_GUIDE.md](./TESTING_GUIDE.md)** - раздел "Решение проблем"

## 🎨 Как выглядят уведомления

### При переключении провайдера (warning):
```
┌─────────────────────────────────────────────┐
│ ⚠️  AI провайдер изменён:                   │
│     Google Gemini → OpenAI GPT         ✕    │
└─────────────────────────────────────────────┘
```
**Цвет:** Оранжевый фон, оранжевая рамка

### При критической ошибке (error):
```
┌─────────────────────────────────────────────┐
│ ❌  Все AI провайдеры недоступны.           │
│     Проверьте API ключи и лимиты.      ✕    │
└─────────────────────────────────────────────┘
```
**Цвет:** Красный фон, красная рамка

---

## 🚀 Как работает

### Поток событий:

1. **Пользователь отправляет сообщение**
2. **aiService пытается использовать Gemini**
3. **Gemini возвращает quota error**
4. **aiService переключается на OpenAI**
5. **🎉 Показывается toast-уведомление:**
   ```
   ⚠️ AI провайдер изменён: Google Gemini → OpenAI GPT
   ```
6. **OpenAI обрабатывает запрос**
7. **Пользователь получает ответ**

## 🎯 Типы уведомлений

### 1. Info (💡)
```typescript
showToast('Информационное сообщение', 'info');
```
**Цвет:** Синий

### 2. Warning (⚠️)
```typescript
showToast('Предупреждение', 'warning');
```
**Цвет:** Оранжевый
**Используется:** При переключении провайдеров

### 3. Success (✅)
```typescript
showToast('Успешная операция', 'success');
```
**Цвет:** Зелёный

### 4. Error (❌)
```typescript
showToast('Ошибка', 'error');
```
**Цвет:** Красный
**Используется:** Когда все провайдеры недоступны

## 💻 Использование в коде

### Показать уведомление:

```typescript
import { showToast } from './components/Toast';

// В любом месте приложения:
showToast('Ваше сообщение', 'info');
showToast('Предупреждение!', 'warning');
showToast('Успех!', 'success');
showToast('Ошибка!', 'error');
```

### Настройка длительности:

По умолчанию: **5000ms (5 секунд)**

Изменить в `Toast.tsx`:
```typescript
<Toast 
  message="Сообщение" 
  type="info" 
  duration={3000}  // 3 секунды
  onClose={...} 
/>
```

## 🎨 Настройка стилей

### Изменить позицию:

В `Toast.tsx` и `ToastContainer.tsx`:
```typescript
// Текущая позиция: top-4 right-4
className="fixed top-4 right-4 z-50"

// Варианты:
// Верх слева:
className="fixed top-4 left-4 z-50"

// Низ справа:
className="fixed bottom-4 right-4 z-50"

// По центру сверху:
className="fixed top-4 left-1/2 transform -translate-x-1/2 z-50"
```

### Изменить цвета:

В `Toast.tsx`:
```typescript

  error: 'bg-red-500',
};
```

## 🎯 Примеры использования

### В компоненте:

```typescript
import { showToast } from '../components/Toast';

// При успешном сохранении:
const handleSave = () => {
  try {
    // ... сохранение
    showToast('Урок успешно сохранён!', 'success');
  } catch (error) {
    showToast('Ошибка сохранения урока', 'error');
  }
};

// При валидации:
const handleValidate = () => {
  if (!isValid) {
    showToast('Пожалуйста, заполните все поля', 'warning');
    return;
  }
  // ...
};

// При загрузке данных:
const handleLoad = async () => {
  showToast('Загрузка данных...', 'info');
  await fetchData();
  showToast('Данные загружены!', 'success');
};
```

## 🔄 Автоматические уведомления

Система автоматически показывает уведомления в следующих случаях:

### 1. Переключение провайдера (warning)
**Когда:** При исчерпании лимита и переключении на резервный провайдер
**Сообщение:** "AI провайдер изменён: [старый] → [новый]"

### 2. Все провайдеры недоступны (error)
**Когда:** Когда ни один провайдер не может обработать запрос
**Сообщение:** "Все AI провайдеры недоступны. Проверьте API ключи и лимиты."

## 🎯 Цель проекта

Интерактивное веб-приложение для изучения немецкого языка с персональным AI-репетитором, который:
- Проверяет правильность переводов
- Объясняет грамматические ошибки
- Адаптируется под уровень ученика
- Использует интервальное повторение для эффективного запоминания

- **ВАЖНО:** `.env` добавлен в `.gitignore`

## 📈 Метрики производительности

### API-запросы
- **Цель:** < 60 запросов / час
- **Текущее:** ~20-30 запросов / урок
- **Оптимизация:** 70% запросов заменены локальной валидацией

### Размер бандла
- **Build size:** ~500KB (gzip)
- **Initial load:** < 2 секунды

### LocalStorage
- **Использовано:** ~100KB на 10 уроков
- **Лимит:** 5-10MB

## 🎯 Ключевые решения

### 1. Почему LocalStorage?
- Простота реализации
- Нет необходимости в backend
- Быстрый доступ к данным
- Оффлайн-доступ к урокам

### 2. Почему локальная валидация?
- Экономия 70% API-запросов
- Мгновенная обратная связь
- Работает без интернета
- Снижение затрат

### 3. Почему Gemini (не ChatGPT)?
- Бесплатный план (60 req/min)
- Официальный SDK (@google/genai)
- Низкая латентность
- Русский язык из коробки

### 4. Почему TypeScript?
- Типобезопасность
- Лучший IntelliSense
- Раннее обнаружение ошибок
- Самодокументирование кода

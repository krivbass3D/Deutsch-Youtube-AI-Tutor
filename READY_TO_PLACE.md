## 🎯 ЧТО НУЖНО СДЕЛАТЬ СЕЙЧАС:

### Найдите в App.tsx место с текстом "Запросы AI" 

Скорее всего это выглядит так:

```tsx
<div className="...">
  <span>Запросы AI: 0/20</span>
</div>
```

### Замените на:

```tsx
<AIProviderSelectorCompact />
```

---

## 📍 Или найдите header Dashboard

Ищите такой код:

```tsx
{currentView === 'dashboard' && (
  <header ...>
    {/* Здесь header */}
  </header>
)}
```

Добавьте селектор в header рядом с кнопкой "Главная".

---

## 🔍 Как найти нужное место

### Вариант 1: Поиск по тексту

Найдите в `App.tsx` строку с "Главная" или "Dashboard" или "0/20"

### Вариант 2: Поиск header

Найдите `<header` в файле App.tsx

### Вариант 3: Добавить в любое место как тест

Просто добавьте в начало return():

```tsx
return (
  <div className="min-h-screen bg-gradient-to-br from-blue-50 to-indigo-100 p-6">
    {/* ДОБАВИТЬ ЗДЕСЬ ДЛЯ ТЕСТА */}
    <div className="mb-4">
      <AIProviderSelectorCompact />
    </div>
    
    {/* Остальной код */}
```

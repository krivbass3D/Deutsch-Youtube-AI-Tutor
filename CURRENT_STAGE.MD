## 💡 Ключевые моменты

### ✨ Что особенного в проекте

```
✅ AI-репетитор, который действительно помогает учиться
✅ Spaced Repetition алгоритм для долгосрочного запоминания
✅ Локальная валидация перед API (экономит 50-70% запросов)
✅ Интуитивный интерфейс на React
✅ Полная документация для разработки
✅ План миграции для масштабирования
```

### 🎯 Главные правила

```
1. 🔴 КРАТКОСТЬ при правильном ответе!
   (максимум 5-7 слов, иначе раздражает ученика)

2. 🔴 TypeScript везде
   (нет any типов, строгая типизация)

3. 🔴 localStorage всегда
   (всё персистит, нельзя потерять данные)

4. 🔴 Локальная валидация первой
   (экономить API-запросы перед Gemini)

5. 🔴 try-catch для всех операций
   (обработка всех ошибок)
```

### 🚨 Что нельзя забывать

```
❌ Не писать длинные ответы ИИ при правильном выполнении
❌ Не использовать any в TypeScript
❌ Не забыть сохранить в localStorage
❌ Не отправлять в API без локальной проверки
❌ Не оставлять ошибки без обработки
```

---

## 🎯 Что такое System Prompt?

**System Prompt** — это инструкция, которая отправляется в Google Gemini API перед каждым запросом пользователя. Она определяет:

- **Кто** — роль модели (репетитор немецкого)
- **Как** — стиль общения (дружелюбный, терпеливый)
- **Что** — функции (проверка ответов, объяснение ошибок)
- **Когда** — условия (при правильном ответе — краткий ответ)

## 📖 Файлы в папке

### main-tutor-prompt.md
**Назначение:** Основной System Prompt для Gemini API

**Содержимое:**
- Роль репетитора
- Режимы работы (проверка упражнений, ответы на вопросы)
- Детальные алгоритмы ответов
- Стиль общения и форматирование
- Специальные правила

**Где используется:**
```typescript
// В geminiService.ts
const response = await client.generateContent({
  systemInstruction: SYSTEM_PROMPT,  // ← Этот файл
  contents: [...]
})
```

### role-definitions.md
**Назначение:** Определение различных ролей и поведений репетитора

**Содержимое:**
- Роль как учителя
- Роль как мотиватора
- Роль как эксперта по языку
- Когда какую роль использовать

---

## 🔄 Как система работает

```
1. Пользователь отправляет ответ
   ↓
2. Это передаётся в Gemini API
   ↓
3. Gemini получает инструкции из System Prompt
   ↓
4. На основе инструкций Gemini генерирует ответ
   ↓
5. Ответ отправляется пользователю
```

## 📝 Как изменить System Prompt

### Шаг 1: Отредактируйте файл
Измените текст в `main-tutor-prompt.md` или `role-definitions.md`

### Шаг 2: Скопируйте в constants.ts
```typescript
// constants.ts
export const SYSTEM_PROMPT = `
[Копируем полный текст из main-tutor-prompt.md]
`
```

### Шаг 3: Протестируйте
Запустите приложение и проверьте, как AI реагирует:
```bash
npm run dev
```

### Шаг 4: Отправьте изменения
Если всё работает — сохраните в git

## 💡 Примеры изменений

### Пример 1: Сделать репетитора более веселым

**Было:**
```
Используйте эмодзи для структурирования (✅ ❌ 💡 📚)
```

**Стало:**
```
Используйте эмодзи для структурирования (✅ ❌ 💡 📚 🎉 🌟)
Может быть, добавьте шутки и весёлые замечания
```

### Пример 2: Сделать объяснения более подробными

**Было:**
```
❌ ИЗБЕГАЙТЕ:
Слишком длинных объяснений (максимум 5-7 строк за раз)
```

**Стало:**
```
⚠️ БАЛАНС:
Объяснения должны быть подробными (максимум 10-15 строк),
но структурированными для ясности
```

## 🔍 Тестирование System Prompt

Чтобы протестировать System Prompt:

1. **Откройте приложение** — `npm run dev`
2. **Выполните упражнение** с нарочно неправильным ответом
3. **Посмотрите на ответ AI** — соответствует ли инструкциям?
4. **Проверьте:**
   - ✅ Краткость при правильном ответе?
   - ✅ Объяснение при ошибке?
   - ✅ Используются ли эмодзи?
   - ✅ Рекомендации из vocabulary?

## ⚠️ Критические правила

Если вы меняете System Prompt, **ОБЯЗАТЕЛЬНО** соблюдайте:

1. **✅ При правильном ответе — максимум 5-7 слов!**
   - Это критично для пользовательского опыта
   - Длинные объяснения раздражают

2. **✅ Всегда давайте подсказку, не готовый ответ**
   - При ошибке ученик должен исправить сам
   - Готовый ответ — это плохой педагогический подход

3. **✅ Используйте примеры из vocabulary урока**
   - Никогда не используйте незнакомые слова
   - Ссылайтесь на текущий контекст

4. **✅ Будьте дружелюбны и мотивирующи**
   - Ошибки — это нормально
   - Никогда не критикуйте
   - Поддерживайте мотивацию

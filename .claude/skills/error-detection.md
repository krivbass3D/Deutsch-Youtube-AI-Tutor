# ❌ Error Detection - Детектирование и объяснение ошибок

> Как识别ить, классифицировать и объяснять ошибки в ответах ученика

---

## 🎯 Цель

Помочь ученику **понять, где ошибка**, **почему** это ошибка и **как её исправить**.

---

## 📋 Типы ошибок в немецком языке

### 1️⃣ ГРАММАТИЧЕСКИЕ ОШИБКИ (Grammar Errors)

**Определение:** Нарушения правил спряжения глаголов, склонения существительных, согласования и т.д.

#### Ошибки с падежами (Cases)

```
Правило: Nominativ (именительный) = кто? что?
         Akkusativ (винительный) = кого? что?
         Dativ (дательный) = кому? чему?
         Genitiv (родительный) = чей? чья?

Пример ошибки:
"Ich sehe den Mann" ✅ (Akkusativ — правильно)
"Ich sehe der Mann" ❌ (Nominativ — неправильно)

Как объяснить:
"После глагола 'sehen' (видеть) нужен Akkusativ (кого? что?).
Правильно: "Ich sehe den Mann", а не "der Mann"."
```

#### Ошибки со спряжением глаголов (Verb Conjugation)

```
Правило: Разные лица требуют разных окончаний
         ich -e, du -st, er/sie/es -t, wir/ihr/sie -en

Пример ошибки:
"Ich geht nach Hause" ❌ (неправильное окончание)
"Ich gehe nach Hause" ✅ (правильное)

Как объяснить:
"Глагол 'gehen' спрягается так: ich gehe, du gehst, er/sie/es geht.
Для 'ich' нужно окончание '-e', а не '-t'."
```

#### Ошибки с временами (Tenses)

```
Правило: Разные времена для разных ситуаций
         Präsens = настоящее
         Perfekt = разговорное прошедшее
         Präteritum = письменное прошедшее

Пример ошибки:
"Ich bin gegangen" ✅ (Perfekt — правильно для разговора)
"Ich geht gestern" ❌ (неправильное время для прошедшего)

Как объяснить:
"Когда говорим о прошедшем, нужно использовать Perfekt или Präteritum.
Используй: 'Ich bin gegangen' или 'Ich ging'."
```

#### Ошибки с модальными глаголами (Modal Verbs)

```
Правило: Модальные глаголы (wollen, müssen, können, mögen, sollen, dürfen)
         требуют инфинитива в конце

Пример ошибки:
"Ich möchte einen Kaffee trinken" ✅ (правильно)
"Ich möchte einen Kaffee trinke" ❌ (неправильно)

Как объяснить:
"После модального глагола 'möchte' нужен инфинитив 'trinken'.
Правильно: 'trinken' в конце предложения, не 'trinke'."
```

#### Ошибки с артиклями (Articles)

```
Правило: Артикли должны соответствовать роду и падежу существительного

Пример ошибки:
"Das ist ein Haus" ✅ (правильный артикль среднего рода)
"Das ist ein Hauses" ❌ (неправильно — лишнее -es)

Как объяснить:
"Слово 'Haus' среднего рода. Артикль 'ein' для среднего рода.
При спряжении не добавляй окончание к существительному."
```

---

### 2️⃣ ОШИБКИ ПОРЯДКА СЛОВ (Word Order Errors)

**Определение:** Слова расставлены в неправильном порядке.

```
Правило немецкого порядка слов:
Основной порядок: Подлежащее - Глагол - Дополнение
                  Subjekt - Verb - Objekt

Пример ошибки:
"Ich nach Hause gehe" ❌ (неправильный порядок)
"Ich gehe nach Hause" ✅ (правильный)

Как объяснить:
"В немецком глагол обычно стоит вторым в предложении.
Правильный порядок: подлежащее (Ich) - глагол (gehe) - остальное."
```

---

### 3️⃣ ЛЕКСИЧЕСКИЕ ОШИБКИ (Vocabulary Errors)

**Определение:** Использование неправильного слова или слова, которого нет в немецком.

```
Правило: Используй правильное слово из vocabulary урока

Пример ошибки:
"Ich gehe zu die Schule" ❌ (перепутана предлог)
"Ich gehe zur Schule" ✅ (правильный предлог)

Как объяснить:
"После 'gehen' используй предлог 'zu' + дательный падеж (zur = zu + der).
Правильно: 'zur Schule', а не 'zu die Schule'."
```

---

### 4️⃣ ОРФОГРАФИЧЕСКИЕ ОШИБКИ (Spelling Errors)

**Определение:** Ошибки в написании букв.

**Примеры:**
- "Haus" → "Hous" ❌
- "schön" → "schön" (не "schon")
- "möchte" → "mochte" ❌

**Как обрабатывать:**
- Если смысл понятен → игнорируйте (не ошибка)
- Если изменяет произношение → укажите на опечатку
- "schon" vs "schön" — это значит разные вещи!

---

### 5️⃣ ПУНКТУАЦИОННЫЕ ОШИБКИ (Punctuation Errors)

**Определение:** Неправильное использование знаков препинания.

**Примеры:**
- Вместо точки — запятая
- Забытая точка в конце
- Лишние запятые

**Как обрабатывать:**
- Менее важно, чем грамматика
- Укажите только если меняет смысл
- Обычно игнорируйте в тестовых ответах

---

## 🔍 Как детектировать ошибки

### Шаг 1: Прочитайте ответ ученика

Прочитайте ответ целиком и поймите, что ученик хотел сказать.

```
Пример: "Ich bin ging nach Hause"
Понимание: Ученик пытался сказать "Я пошёл домой"
```

### Шаг 2: Определите тип ошибки

Какой из 5 типов это ошибка?

```
Ошибка: "Ich bin ging nach Hause"
Тип: Грамматическая (неправильное время и спряжение)
```

### Шаг 3: Локализуйте ошибку

Укажите точное место ошибки.

```
Ошибка в: "bin ging" (конфликт времён)
Правильно: "bin gegangen" (Perfekt) или просто "ging" (Präteritum)
```

### Шаг 4: Объясните правило

Объясните, какое правило нарушено.

```
"Для прошедшего разговорного времени (Perfekt) используем:
sein/haben (в Präsens) + Partizip II (третья форма глагола)
'gehen' → 'bin gegangen' (не 'bin ging')"
```

### Шаг 5: Предложите исправление

Дайте подсказку, как исправить (не готовый ответ).

```
"Используй Partizip II: 'gehen' → 'gegangen'
Должно быть: 'Ich bin gegangen nach Hause'"
```

## 📊 Как классифицировать ошибку по серьёзности

### 🔴 ГРУБЫЕ ОШИБКИ (Major Errors)
**Влияют на смысл**

```
Примеры:
- "Ich sehe einen Mann" vs "Ich sehe eine Frau" (другой смысл)
- "Ich bin gegangen" vs "Ich bin gekommen" (противоположный смысл)
- Неправильное время, меняющее смысл

Как обрабатывать:
Обязательно объясните, почему это ошибка
Дайте подсказку, как исправить
Попросите переделать
```

### 🟡 СРЕДНИЕ ОШИБКИ (Medium Errors)
**Вызывают недопонимание**

```
Примеры:
- Неправильный падеж (нужен Akkusativ, написан Nominativ)
- Неправильный артикль в контексте
- Ошибка в спряжении глагола

Как обрабатывать:
Объясните правило
Дайте подсказку
Попросите переделать
```

### 🟢 МЕЛКИЕ ОШИБКИ (Minor Errors)
**Не влияют на понимание**

```
Примеры:
- Опечатка в написании
- Лишний/пропущенный пробел
- Забытая точка в конце
- Неправильный капитал

Как обрабатывать:
Можно игнорировать
Если указываете — делайте это мягко
"Маленькая опечатка: 'Hous' → 'Haus'"
```


### Примеры полных объяснений

#### Ошибка 1: Неправильный падеж

```
❌ Ошибка в падеже: используется Nominativ вместо Akkusativ

📚 Правило:
После глагола "sehen" (видеть) нужен Akkusativ (кого? что?).
В Nominative говорим "der Mann", а в Akkusativ говорим "den Mann".

💡 Подсказка:
Замени "der" на "den" и попробуй ещё раз!

Попробуйте ещё раз! 🔄
```

#### Ошибка 2: Неправильное спряжение

```
❌ Ошибка в спряжении: "ich geht" должно быть "ich gehe"

📚 Правило:
Глагол "gehen" спрягается так:
- ich gehe (окончание -e)
- du gehst (окончание -st)
- er/sie/es geht (окончание -t)

💡 Подсказка:
Для "ich" используй окончание "-e", а не "-t".

Попробуйте ещё раз! 🔄
```

#### Ошибка 3: Неправильный порядок слов

```
❌ Ошибка в порядке слов: глагол должен быть вторым

📚 Правило:
В немецком порядок слов: Подлежащее - Глагол - Остальное
"Ich gehe nach Hause" (не "Ich nach Hause gehe")

💡 Подсказка:
Переставь слова так, чтобы глагол был вторым словом.

Попробуйте ещё раз! 🔄
```

#### Ошибка 4: Неправильное время

```
❌ Ошибка во времени: "Ich geht gestern" неправильно

📚 Правило:
Для прошедшего времени используй Perfekt или Präteritum:
- Perfekt: Ich bin gegangen (разговорное)
- Präteritum: Ich ging (письменное)

💡 Подсказка:
Используй одно из этих времён для выражения прошлого действия.

Попробуйте ещё раз! 🔄
```

## 🚫 Частые ошибки и как их объяснять

### Ошибка: Забывают спрягать глаголы

```
Ученик: "Ich gehen"
Правильно: "Ich gehe"

Объяснение:
"Глаголы меняют форму в зависимости от подлежащего.
Для 'ich' (я) глагол 'gehen' становится 'gehe'.
Для 'er/sie/es' (он/она/оно) будет 'geht'."
```

### Ошибка: Путают Perfekt и Präsens

```
Ученик: "Ich bin geht"
Правильно: "Ich bin gegangen" или "Ich gehe"

Объяснение:
"Если используешь 'bin' (Perfekt), нужна третья форма глагола (Partizip II).
'Gehen' → 'gegangen' (не 'geht').
Или просто используй Präsens: 'Ich gehe'."
```

### Ошибка: Забывают артикли

```
Ученик: "Ich sehe Mann"
Правильно: "Ich sehe einen Mann"

Объяснение:
"В немецком почти все существительные нуждаются в артикле.
После глагола 'sehen' (видеть) нужен неопределённый артикль 'einen'
(потому что 'Mann' — мужского рода, Akkusativ)."
```

### Ошибка: Путают Nominativ и Akkusativ

```
Ученик: "Ich gebe die Buch der Mädchen" (всё в Nominativ)
Правильно: "Ich gebe das Buch dem Mädchen"

Объяснение:
"При передаче (давать) используются разные падежи:
- Кому? (дательный = Dativ) = dem Mädchen
- Что? (винительный = Akkusativ) = das Buch"
```

## 🎯 Когда игнорировать ошибку

### ✅ ИГНОРИРУЙТЕ:

1. **Опечатки** (если смысл понятен)
   - "shcön" вместо "schön" — OK, смысл ясен

2. **Капитализацию** (в контексте упражнения)
   - "das haus" вместо "das Haus" — не ошибка

3. **Пунктуацию** (если не меняет смысл)
   - Запятая вместо точки — не критично

4. **Артикли в скобках** (если они опциональные)
   - "das (Haus)" = можно писать "das Haus" или просто "Haus"

### ❌ НЕ ИГНОРИРУЙТЕ:

1. **Грамматические ошибки** (падежи, спряжение, времена)
2. **Ошибки, меняющие смысл** ("schon" vs "schön")
3. **Неправильный выбор слова** (из vocabulary)
4. **Порядок слов** (в сложных предложениях)

## 🚀 Примеры детектирования ошибок

### Пример 1: Комплексная ошибка

```
Задание: Напишите "Я вижу красивый дом"

Ученик пишет: "Ich sehe schönes Haus"

Анализ ошибок:
1. Артикль: отсутствует "ein"
2. Согласование: "schönes" должно быть "schönen" (Akkusativ)
3. Артикль: "Haus" нуждается в артикле

Объяснение:
"👍 Хорошая попытка! Вы правильно использовали 'sehen' и 'schön'.

❌ Но есть ошибки в артиклях и согласовании:
- После 'sehen' нужен Akkusativ
- Прилагательное должно согласовываться: 'schönen'
- Нужен артикль перед существительным: 'ein'

💡 Подсказка: 
'Ich sehe einen schönen Haus' (нужно согласовать все слова в Akkusativ).

Попробуйте ещё раз! 🔄"
```

### Пример 2: Простая ошибка

```
Задание: "Он идёт в школу"

Ученик пишет: "Er geht zu Schule"

Ошибка: Неправильный предлог/падеж

Объяснение:
"❌ Небольшая ошибка: 'zu Schule' → 'zur Schule'

📚 Правило:
После глагола 'gehen' + предлог 'zu' → используй дательный падеж.
'zu' + 'der' = 'zur' (сокращение)

💡 Подсказка:
Замени 'zu Schule' на 'zur Schule'.

Попробуйте ещё раз! 🔄"
```

## 🎓 Для новичков

При детектировании ошибки:

1. **Прочитайте** ответ целиком
2. **Поймите**, что ученик хотел сказать
3. **Найдите** что неправильно
4. **Определите тип** (грамматика, лексика и т.д.)
5. **Объясните правило** в 2-3 предложениях
6. **Дайте подсказку** как исправить
7. **Попросите переделать** — не давайте ответ!

**Главное:** Будьте конкретны и доброжелательны! ✨

## 📌 Что такое DeutschMeister?

**DeutschMeister** — интерактивное приложение для изучения немецкого языка с AI-репетитором.

### Основные возможности:
- ✅ Изучение лексики с интервальным повторением
- ✅ Практические упражнения с проверкой AI
- ✅ Режим экзамена для самопроверки
- ✅ Локальная валидация (без ненужных API-запросов)
- ✅ Отслеживание прогресса и статистики

### Стек технологий:
- **Frontend:** React 19 + TypeScript 5
- **Bundler:** Vite 6
- **Styling:** Tailwind CSS 4
- **AI API:** Google Gemini 2.0 Flash
- **Storage:** Browser LocalStorage

## ⚡ Критические правила для Claude

### 🤖 **Работая с репетитором**
1. **При правильном ответе — максимальная краткость!**
   - ✅ Верно!
   - ✅ Правильно! Отличный порядок слов.
   - ❌ Не пишите длинные объяснения

2. При ошибке — объясните, дайте подсказку, пусть переделает

3. Берите примеры из текущего урока (из vocabulary)

### 💻 **Разрабатывая код**
1. Используйте **TypeScript** (строгая типизация)
2. **Функциональные компоненты** с Hooks
3. Следуйте **паттернам** в `patterns/`
4. **Всегда** сохраняйте в localStorage
5. **Обрабатывайте ошибки** с try-catch

### 📦 **Экономия API-запросов**
1. Используйте **локальную валидацию** где возможно
2. Ограничивайте **историю чата** (последние 3 сообщения)
3. **Отслеживайте** использованные запросы
4. Информируйте пользователя о **лимитах**

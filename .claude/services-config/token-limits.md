> Конфигурация лимитов Google Gemini API и управление токенами

## 📊 Лимиты Google Gemini API (Бесплатный тариф)

### Основные лимиты

```
Модель: gemini-2.0-flash

Запросы в минуту:     60 запросов/мин
Запросы в день:       1,500 запросов/день
Токены в минуту:      Неограниченно
```

### Что такое запрос?

```
1 запрос = 1 отправка текста к Gemini API

Примеры 1 запроса:
- Проверка ответа на упражнение
- Ответ на вопрос ученика
- Объяснение ошибки

БЕСПЛАТНО (не считаются):
- Локальная валидация (в браузере)
- Загрузка уроков (из JSON)
- Сохранение в localStorage
```

### Что такое токен?

```
1 токен ≈ 4 символа текста

Примеры:
- Слово "Hallo" = 1 токен
- Фраза "Guten Morgen" = 2 токена
- Параграф текста = 100-200 токенов

Расчёт запроса:
Запрос к API = входные токены + выходные токены
```

## ⏱️ Сброс лимитов

### По дням

```
Лимит в день: 1,500 запросов

Сброс: Каждые 24 часа в 00:00 UTC

Примеры:
- Сегодня сделал 1500 запросов → ЛИМИТ
- Завтра в 00:01 → Лимит СБРОШЕН, есть 1500 запросов

Осторожно: Если ты в часовом поясе UTC+3:
- Сброс происходит в 03:00 твоего времени
- Не в полночь!
```

### По минутам

```
Лимит в минуту: 60 запросов

Сброс: Каждую минуту

Пример:
- 00:00:00 - 00:00:59 → максимум 60 запросов
- 00:01:00 - 00:01:59 → ещё 60 запросов

Если превышу в одну минуту:
→ Получу ошибку 429 (Rate limit exceeded)
→ Нужно ждать следующей минуты
```

## 🛡️ Как не превышать лимиты?

### Стратегия 1: Локальная валидация

```
✅ ПРАВИЛЬНО:
1. Сначала проверяй локально (БЕЗ API!)
2. Только если локально не удалось → вызови API

Экономия:
- 50-70% запросов экономятся на локальной валидации
- При 100 упражнениях в день: 50-70 запросов вместо 100
```

### Стратегия 2: Ограничение истории

```
✅ ПРАВИЛЬНО:
const history = messages.slice(-3)  // Только 3 последних сообщения

Экономия:
- Меньше токенов в запросе = быстрее и дешевле
- Хватает контекста для ответа
```

### Стратегия 3: Кеширование ответов

```
⚠️ СЛОЖНО, но эффективно:
- Если один и тот же вопрос повторяется несколько раз
- Сохранить ответ в localStorage
- Вернуть сохранённый ответ

Пример:
Вопрос "Как спрягается глагол gehen?"
- 1-й раз: вызываем API (1 запрос)
- 2-й раз: берём из localStorage (0 запросов)
- 3-й раз: берём из localStorage (0 запросов)
```

### Стратегия 4: Батчинг

```
⚠️ ОЧЕНЬ СЛОЖНО, но максимально эффективно:
- Собрать несколько запросов
- Отправить одним запросом
- Разделить результаты

Пример:
Вместо 10 отдельных запросов проверки:
- Отправить все 10 в один запрос
- Получить 10 проверок в одном ответе
- Экономия: 90% запросов!
```

## ⚠️ Что происходит при превышении лимитов?

### Превышение лимита в минуту (60)

```
Ошибка: 429 Too Many Requests

Код ошибки:
{
  "error": {
    "code": 429,
    "message": "Resource has been exhausted"
  }
}

Решение:
- Подождить 1 минуту
- Повторить запрос

В приложении:
→ Показать пользователю: "Подождите немного"
→ Предложить использовать локальную валидацию
```

### Превышение лимита в день (1500)

```
Ошибка: 429 / RESOURCE_EXHAUSTED

Код ошибки:
{
  "error": "Quota exceeded for quota metric 'requests'..."
}

Решение:
- ЖДАТЬ ДО ЗАВТРА (00:00 UTC)
- Приложение должно отключить API функции

В приложении:
→ Показать пользователю: "Лимит достигнут, приходите завтра"
→ Позволить использовать локальную валидацию
→ Отключить кнопку отправки к API
```

## 🚨 Обработка ошибок

### Код для обработки

```typescript
// geminiService.ts
catch (error: any) {
  const message = error?.message || JSON.stringify(error)
  
  // Обработка 429 (Rate limit)
  if (message.includes('429') || message.includes('RESOURCE_EXHAUSTED')) {
    const isMinuteLimit = requestCountThisMinute >= 60
    const isDayLimit = requestsToday >= 1500
    
    if (isDayLimit) {
      throw new Error(`Лимит API на день исчерпан (${requestsToday}/1500). 
        Попробуйте завтра. Используйте локальную валидацию для проверки.`)
    }
    
    if (isMinuteLimit) {
      throw new Error('Слишком много запросов в минуту. Подождите немного.')
    }
  }
  
  // Другие ошибки
  console.error('❌ Ошибка API:', error)
  throw error
}
```

## 📈 Оптимизация использования

### До оптимизации

```
100 упражнений в день
× 1 запрос на упражнение
= 100 запросов в день

Использование: 100 / 1500 = 6.7%
```

```
100 упражнений в день
× 0.3 запроса (остальное локально)
= 30 запросов в день

Использование: 30 / 1500 = 2%

Экономия: 70% запросов!
```

### Результат

```
Вместо 30 дней (100 упр/день):
→ Можешь учиться 50 дней (с локальной валидацией)!
```

## 🎓 Для новичков

**Лимиты** — это как зарплата:

```
Зарплата в месяц: 1500 рублей (дневной лимит)
В день зарплата: 50 рублей (1500 / 30)

Если потратишь всё сразу в первый день:
→ Остаток месяца без денег!

Нужно учиться тратить разумно:
→ Используй бесплатные методы (локальная валидация)
→ Используй платные методы (API) только когда нужно
→ Планируй расходы на месяц
```

Лимиты API работают так же!

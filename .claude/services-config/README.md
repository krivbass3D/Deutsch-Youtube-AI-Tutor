# 🔧 Services Config - Конфигурация сервисов

> Технические конфигурации для всех сервисов приложения DeutschMeister

---

## 📚 Содержание

1. **gemini-api-config.md** — Конфигурация Google Gemini API
2. **validation-rules.md** — Правила локальной валидации ответов
3. **spaced-repetition-config.md** — Конфигурация алгоритма SM-2
4. **token-limits.md** — Лимиты API запросов и токенов

---

## 🎯 Что здесь?

В этой папке собраны все **конфигурационные параметры** сервисов:

### geminiService.ts
- Модель: `gemini-2.0-flash`
- Temperature: 0.7
- История сообщений: 3 последних

### validationService.ts
- Нормализация текста
- Правила совпадения ответов
- Когда обращаться к API

### spacedRepetition.ts
- Алгоритм SM-2
- Интервалы повторения
- Коэффициенты сложности

### tokenTracker.ts
- Лимиты: 60 в минуту, 1500 в день
- Отслеживание использованных запросов
- Сброс счётчика в 00:00

## 🛠️ Для разработчиков

При добавлении нового сервиса:

1. Создайте файл конфигурации в `.claude/services-config/`
2. Документируйте все параметры
3. Объясните, как их менять
4. Обновите этот README.md

**Пример файла конфигурации:**

```markdown
# My New Service Config

## Параметры
- parameter1: value1
- parameter2: value2

## Как менять
1. Откройте файл service.ts
2. Измените переменную MY_PARAM

## Примеры
```

# 🔄 Spaced Repetition Config - Конфигурация алгоритма повторения

> Конфигурация алгоритма SM-2 (SuperMemo 2) для интервального повторения слов

---

## 🎯 Что такое Spaced Repetition?

**Spaced Repetition** — это метод обучения, при котором информация повторяется через **возрастающие интервалы времени**.

**Как работает:**

```
День 1: Выучи слово
День 2: Повтори слово
День 4: Повтори слово
День 7: Повтори слово
День 14: Повтори слово
День 30: Повтори слово
```

**Преимущества:**
- ✅ Максимальное запоминание
- ✅ Минимум повторений (всё остальное)
- ✅ Научно доказано (Hermann Ebbinghaus)
- ✅ Естественное забывание = лучше учится

---

## 🧮 Алгоритм SM-2

**SM-2** — это конкретный алгоритм, разработанный Piotr Wozniak в 1987 году.

### Основные переменные

```typescript
interface SpacedRepetitionData {
  word: string                    // Слово
  lastReview: string              // ISO дата последнего повтора
  nextReview: string              // ISO дата следующего повтора
  interval: number                // Дней до следующего повтора
  easeFactor: number              // Коэффициент лёгкости (1.3-2.5)
  reviewCount: number             // Количество повторений
  quality: number                 // Качество последнего ответа (0-5)
}
```

---

### Расчёты в SM-2

#### 1. Интервал (Interval)

```
Первый повтор:    I(1) = 1 день
Второй повтор:    I(2) = 3 дня
Третий повтор:    I(n) = I(n-1) × EF
```

**Примеры:**
```
Если EF = 2.0:
- День 1
- День 3 (3 × 1)
- День 6 (3 × 2)
- День 12 (6 × 2)
- День 24 (12 × 2)
- День 48 (24 × 2)
→ Максимум 30 дней

Если EF = 1.5:
- День 1
- День 3 (3 × 1)
- День 4.5 (3 × 1.5)
- День 6.75 (4.5 × 1.5)
→ Более частые повторения
```

#### 2. Коэффициент лёгкости (Ease Factor)

```
EF':= EF + (0.1 - (5-q) × (0.08 + (5-q) × 0.02))

Где:
- EF = текущий коэффициент
- q = качество ответа (0-5)
- EF':= новый коэффициент
```

**Упрощённо:**
```
Если ответ правильный (q=5):
  EF новое = EF старое + 0.1
  (легче стать еще легче)

Если ответ правильный (q=4):
  EF новое = EF старое + 0.0
  (остаётся тем же)

Если ответ неправильный (q=0):
  EF новое = EF старое - 0.8
  (становится сложнее)
```

#### 3. Минимум EF

```
Минимальное значение EF: 1.3

Если расчёт дал меньше:
  EF_new = 1.3
```

**Почему 1.3?**
- Минимальный интервал = 1 день
- Должен быть хоть какой-то прогресс
- EF < 1.3 = слово станет вечно сложным

## ⚙️ Текущая конфигурация

### Начальные значения

```typescript
// Когда слово ВПЕРВЫЕ показано ученику
const INITIAL_EASE_FACTOR = 2.5  // Изначально предполагается легко
const INITIAL_INTERVAL = 1        // Первое повторение через 1 день
const INITIAL_QUALITY = 0         // Ещё не отвечал
```

### Минимум и максимум

```typescript
const MIN_EASE_FACTOR = 1.3      // Очень сложное слово
const MAX_EASE_FACTOR = 2.5      // Очень лёгкое слово
const MAX_INTERVAL = 30          // Максимум 30 дней между повторениями
```

### Шкала качества (Quality Scale)

```typescript
// Ученик отвечает на вопрос. Как оценить качество?

5 - Идеальный ответ (с первой попытки, быстро)
4 - Правильный ответ (но медленнее)
3 - Правильный ответ (с колебаниями, правильно вспомнил)
2 - Неправильный ответ (но близко к правильному)
1 - Неправильный ответ (но помнит что-то)
0 - Совсем неправильный (полностью забыл)
```

## 🔄 Как работает алгоритм?

### Сценарий 1: Новое слово

```
Слово: "das Haus"
Статус: НОВОЕ (не показывалось ранее)

Инициализация:
- interval = 1 день
- easeFactor = 2.5
- lastReview = сегодня
- nextReview = завтра
```

### Сценарий 2: Правильный ответ (quality = 5)

```
Слово: "das Haus"
Текущий interval: 1 день
Текущий EF: 2.5
Ответ ученика: ✅ Правильный (quality = 5)

Расчёты:
EF_new = 2.5 + 0.1 = 2.6 (но MAX = 2.5, поэтому EF_new = 2.5)
interval_new = 1 × 2.5 = 2.5 → округляем до 3 дней

Новые значения:
- interval = 3 дня
- easeFactor = 2.5
- nextReview = через 3 дня
```

### Сценарий 3: Неправильный ответ (quality = 0)

```
Слово: "die Katze"
Текущий interval: 7 дней
Текущий EF: 2.2
Ответ ученика: ❌ Неправильный (quality = 0)

Расчёты:
EF_new = 2.2 - 0.8 = 1.4
interval_new = 1 день (сброс)

Новые значения:
- interval = 1 день
- easeFactor = 1.4
- nextReview = через 1 день
- Слово вернулось в начало!
```

## 📊 Примеры прогрессии

### Слово "лёгкое" (правильные ответы)

```
Начало: EF = 2.5, interval = 1

1. Правильно (q=5)
   EF: 2.5 → 2.5, interval: 1 → 3 дня
   
2. Правильно (q=5)
   EF: 2.5 → 2.5, interval: 3 → 8 дней
   
3. Правильно (q=5)
   EF: 2.5 → 2.5, interval: 8 → 20 дней
   
4. Правильно (q=5)
   EF: 2.5 → 2.5, interval: 20 → 30 дней (MAX)
   
Итог: Каждые 30 дней один раз!
```

### Слово "среднее" (смешанные ответы)

```
Начало: EF = 2.5, interval = 1

1. Правильно (q=5)
   EF: 2.5 → 2.5, interval: 1 → 3 дня
   
2. Частично (q=3)
   EF: 2.5 - 0.27 = 2.23, interval: 3 → 7 дней
   
3. Правильно (q=4)
   EF: 2.23 - 0.02 = 2.21, interval: 7 → 15 дней
   
4. Неправильно (q=0)
   EF: 2.21 - 0.8 = 1.41, interval: 15 → 1 день (СБРОС!)
   
5. Правильно (q=5)
   EF: 1.41 + 0.1 = 1.51, interval: 1 → 1.5 ≈ 2 дня

Итог: Более сложное слово, требует больше внимания
```

### Слово "сложное" (много ошибок)

```
Начало: EF = 2.5, interval = 1

1. Неправильно (q=0)
   EF: 2.5 - 0.8 = 1.7, interval: 1 → 1 день
   
2. Неправильно (q=0)
   EF: 1.7 - 0.8 = 0.9 → MIN = 1.3, interval: 1 → 1 день
   
3. Неправильно (q=0)
   EF: 1.3 - 0.8 = 0.5 → MIN = 1.3, interval: 1 → 1 день
   
4. Правильно (q=3)
   EF: 1.3 - 0.27 = 1.03 → MIN = 1.3, interval: 1 → 1 день
   
5. Правильно (q=4)
   EF: 1.3 - 0.02 = 1.28 → MIN = 1.3, interval: 1 → 1 день

Итог: Очень сложное слово! Нужно учить его каждый день!
```

## 🎛️ Как менять конфигурацию?

### Сделать слова "проще" (более редкие повторения)

```typescript
// Увеличь начальный EF
const INITIAL_EASE_FACTOR = 3.0  // было 2.5

// Результат: интервалы будут больше
```

### Сделать слова "сложнее" (более частые повторения)

```typescript
// Уменьши начальный EF
const INITIAL_EASE_FACTOR = 1.5  // было 2.5

// Результат: интервалы будут меньше
```

### Увеличить максимальный интервал

```typescript
// Увеличь MAX интервал
const MAX_INTERVAL = 60  // было 30 дней

// Результат: слова будут повторяться реже, но дольше
// ⚠️ Риск: забудут слова на длинном интервале
```

### Менять шкалу качества

```typescript
// Где вычисляется quality в TutorChat.tsx:
const quality = isCorrect ? 5 : 0  // Сейчас: либо 5, либо 0

// Можно сделать более детальной:
const quality = isCorrect 
  ? (isFirstTry ? 5 : 4)           // 5 = с первой, 4 = со второй
  : (isCloseToCorrect ? 2 : 0)    // 2 = близко, 0 = далеко
```

## 💡 Tips для настройки

### Совет 1: Найти баланс

```
Если слова повторяются слишком часто:
→ Увеличь INITIAL_EASE_FACTOR (более оптимистично)

Если слова забываются:
→ Уменьши MAX_INTERVAL (повторения чаще)
```

### Совет 2: Отслеживать метрики

```typescript
// Сколько слов нужно повторить сегодня?
const todaysWords = getNextReviewWords(vocabulary)
console.log(`Сегодня: ${todaysWords.length} слов`)

// Какой средний EF?
const avgEF = vocabulary.reduce((sum, w) => sum + w.easeFactor, 0) / vocabulary.length
console.log(`Средний EF: ${avgEF.toFixed(2)}`)
```

## 🎓 Для новичков

**SM-2** — это как система тренировки мышц:

```
Если правильно:
→ Отдыхай дольше (интервал растёт)
→ Мышца уже прокачана

Если неправильно:
→ Тренируйся снова завтра (интервал = 1 день)
→ Мышца ещё слаба

Чем чаще правильно:
→ Тем дольше отдыхаешь
→ Тем реже её нужно тренировать
```

Алгоритм SM-2 оптимизирует этот процесс математически!

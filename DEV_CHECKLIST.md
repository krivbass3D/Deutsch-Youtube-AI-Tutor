## Git Workflow

### Создание ветки
```bash
git checkout -b feature/название-фичи
# или
git checkout -b fix/название-бага
```

### Коммит
```bash
git add .
git commit -m "feat: описание изменений"
```

**Префиксы коммитов:**
- `feat:` - новая функциональность
- `fix:` - исправление бага
- `docs:` - изменения в документации
- `style:` - форматирование, стили
- `refactor:` - рефакторинг кода
- `test:` - добавление тестов
- `chore:` - обновление зависимостей, конфигурации

### Пуш
```bash
git push origin feature/название-фичи
```

## Debugging Checklist

### Ошибка в консоли
- [ ] Прочитать полный stack trace
- [ ] Проверить, какой файл и строка
- [ ] Проверить типы данных
- [ ] Добавить console.log для отладки
- [ ] Проверить network запросы (если API)

### Компонент не рендерится
- [ ] Проверить, что компонент экспортирован
- [ ] Проверить, что компонент импортирован
- [ ] Проверить props
- [ ] Проверить условия рендеринга (if, ternary)
- [ ] Проверить консоль на ошибки

### Данные не сохраняются
- [ ] Проверить console.log при сохранении
- [ ] Открыть DevTools → Application → Local Storage
- [ ] Проверить формат данных
- [ ] Проверить, что cookies включены
- [ ] Проверить режим приватного просмотра

### Стили не применяются
- [ ] Проверить правильность Tailwind классов
- [ ] Проверить `tailwind.config.js`
- [ ] Перезапустить dev сервер
- [ ] Проверить порядок классов (последний выигрывает)
- [ ] Проверить responsive классы (md:, lg:)

## Quick Commands Reference

```bash
# Разработка
npm run dev              # Запуск dev сервера
npm run build            # Production build
npm run preview          # Предпросмотр build

# Проверки
npx tsc --noEmit         # TypeScript проверка

git log --oneline -10    # Последние 10 коммитов
git stash                # Временно спрятать изменения
git stash pop            # Вернуть спрятанные изменения
```

## When Something Goes Wrong

### "Не работает!"
1. Открыть консоль (F12)
2. Посмотреть на ошибки
3. Гуглить ошибку
4. Проверить Network tab
5. Спросить Claude 😊

### "Странная ошибка после npm install"
```bash
rm -rf node_modules
rm package-lock.json
npm install
```

### "Dev сервер не запускается"
```bash
# Проверить порт 5173
lsof -i :5173
# Убить процесс если нужно
kill -9 <PID>
```

### "TypeScript ругается на всё"
```bash
# Перезапустить TypeScript сервер в VS Code
Ctrl+Shift+P → "TypeScript: Restart TS Server"
```

## 🚀 Как работает

### Поток действий:

1. **Пользователь открывает приложение**
   - Загружается последний выбранный провайдер из LocalStorage
   - По умолчанию: Google AI Studio

2. **Пользователь кликает на селектор**
   - Открывается выпадающее меню с 2 вариантами

3. **Пользователь выбирает ChatGPT**
   - Выбор сохраняется в LocalStorage
   - Меню закрывается
   - В селекторе показывается "ChatGPT"

4. **Пользователь отправляет сообщение**
   - aiService читает выбор из LocalStorage
   - Использует ChatGPT API
   - Возвращает ответ

## 🔧 Технические детали

### LocalStorage ключ:
```typescript
const PROVIDER_STORAGE_KEY = 'selected_ai_provider';

// Сохранение:
localStorage.setItem('selected_ai_provider', 'openai');

// Чтение:
const provider = localStorage.getItem('selected_ai_provider'); // 'openai' или 'gemini'
```

### Функции для работы с выбором:

```typescript
// Получить текущий провайдер
import { getSelectedProvider } from './components/AIProviderSelector';
const provider = getSelectedProvider(); // 'gemini' | 'openai'

// Установить провайдер программно
import { setSelectedProvider } from './components/AIProviderSelector';
setSelectedProvider('openai');
```

## 📊 Преимущества нового подхода

### По сравнению с автоматическим переключением:

**✅ Контроль пользователя:**
- Пользователь сам выбирает какой AI использовать
- Нет неожиданных переключений
- Прозрачность и понятность

**✅ Простота кода:**
- Меньше логики (~180 строк вместо ~400)
- Нет сложного state management
- Легче поддерживать и расширять

**✅ Лучший UX:**
- Красивый UI для выбора
- Сохранение выбора между сессиями
- Понятные описания провайдеров

**✅ Меньше ошибок:**
- Нет счётчиков ошибок и fallback логики
- Нет toast-уведомлений о переключении
- Простые сообщения об ошибках

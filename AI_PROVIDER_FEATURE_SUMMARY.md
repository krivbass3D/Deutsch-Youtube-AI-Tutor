- `resetProviders()` - сброс счётчиков ошибок

**Особенности:**
- Автоматическое переключение при quota errors

## 🔧 Техническая информация

### Поддерживаемые провайдеры:

**1. Google Gemini (по умолчанию)**
- Модель: `gemini-2.0-flash`
- Бесплатный лимит: 15 RPM, 1500 RPD
- Стоимость: $0.000125/$0.000375 за 1K chars

**2. OpenAI (резервный)**
- Модель: `gpt-4o-mini` (или `gpt-4o`)
- Лимиты: зависят от tier
- Стоимость: $0.15/$0.60 за 1M tokens (mini)

### Логика переключения:

```
1. Попытка Gemini
   ├─ Успех → ответ
   └─ Quota error
       ├─ errorCount++
       └─ if errorCount >= 3
           ├─ mark unavailable
           └─ switch to OpenAI
               ├─ Успех → ответ
               └─ Error → сообщение об ошибке
```

### Ошибки вызывающие переключение:
- `quota exceeded`
- `rate limit`
- `429 Too Many Requests`
- `Resource has been exhausted`

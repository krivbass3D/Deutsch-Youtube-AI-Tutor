# Claude Development Context

## Quick Project Overview
This is a German language learning application that uses YouTube videos and AI-powered spaced repetition for effective learning.

## Tech Stack
- **Frontend**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **AI**: Claude API for lesson generation and feedback
- **Video**: YouTube IFrame API
- **Storage**: Browser LocalStorage

## Key Components Structure
```
components/
├── VideoPlayer.tsx - YouTube video integration
├── LessonDisplay.tsx - Main lesson interface
├── SpacedRepetition.tsx - SRS algorithm implementation
├── ProgressTracker.tsx - Learning progress visualization
└── ... (other components)
```

## Development Workflow

### Before Making Changes
1. Check current file structure: `Filesystem:list_directory`
2. Read relevant files: `Filesystem:read_file`
3. Review documentation in ARCHITECTURE.md and DEV_GUIDE.md

### When Adding Features
1. Update types.ts if new types needed
2. Update constants.ts for new configuration
3. Add/modify components
4. Update relevant documentation
5. Test with `npm run dev`

### Code Style Guidelines
- Use functional components with hooks
- TypeScript strict mode enabled
- Follow Tailwind utility-first approach
- Keep components focused and reusable
- Add JSDoc comments for complex functions

- API calls are in `services/` directory
- Always handle errors gracefully
- Use environment variables for API keys (.env file)

### Modifying Lesson Data
- Lessons stored in `lessons.json`
- Follow existing structure
- Validate JSON before committing

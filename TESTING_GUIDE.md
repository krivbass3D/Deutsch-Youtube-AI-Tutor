# DeutschMeister - ИИ-репетитор немецкого языка

Приложение для изучения немецкого языка с ИИ-репетитором на базе Google Gemini API.

## 🧪 Инструкция по тестированию

### Тест 1: Проверка сохранения уроков
1. Откройте приложение в браузере
2. Откройте консоль разработчика (F12)
3. Добавьте новый урок через интерфейс
4. В консоли вы должны увидеть: `✅ Урок #X добавлен`
5. В правом верхнем углу появится индикатор "💾 Сохранение..." → "✅ Сохранено"
6. **Обновите страницу (F5)**
7. В консоли вы должны увидеть: `✅ Загружено N уроков из localStorage`
8. **Ожидаемый результат:** Добавленный урок остался в списке ✅

### Тест 2: Проверка удаления урока
1. Наведите курсор на карточку любого урока
2. Должна появиться кнопка 🗑️ в правом верхнем углу карточки
3. Нажмите на кнопку удаления
4. Должно появиться окно подтверждения
5. Подтвердите удаление
6. В консоли: `✅ Урок #X удалён`
7. **Обновите страницу (F5)**
8. **Ожидаемый результат:** Урок удалён и больше не появляется ✅

### Тест 3: Проверка навигации назад
1. Откройте любой урок
2. Начните практику
3. Перейдите на 3-е задание
4. Нажмите кнопку "← Назад"
5. **Ожидаемый результат:** Открылось 2-е задание ✅
6. На первом задании кнопка "Назад" должна быть неактивной (серая)

### Тест 4: Проверка статистики
1. Начните выполнять упражнения
2. Отправьте 2 правильных ответа (ИИ ответит "✅ Верно!")
3. Отправьте 1 неправильный ответ
4. Наверху справа должно быть: ✅ 2  ❌ 1
5. **Ожидаемый результат:** Счётчики обновляются корректно ✅

### Тест 5: Проверка прогресс-бара
1. Начните урок с 10 заданиями
2. На 5-м задании прогресс-бар должен быть заполнен примерно на 50%
3. Под прогресс-баром должен быть процент: "50%"
4. **Ожидаемый результат:** Прогресс отображается корректно ✅

### Тест 6: Проверка экрана итоговой статистики
1. Выполните урок до конца
2. На последнем задании нажмите "Следующая"
3. **Ожидаемый результат:** Открылся экран "🎉 Урок завершён!" с статистикой ✅
4. Не должно выбросить на главную страницу
5. Должны отображаться: количество правильных/неправильных ответов и процент

### Тест 7: Проверка пропуска лексики
1. Откройте новый урок
2. На экране урока должна быть кнопка "Пропустить →"
3. Нажмите "Пропустить"
4. **Ожидаемый результат:** Этап 2 (Практика) стал доступен ✅
5. Можно сразу начать упражнения

### Тест 8: Проверка продолжения с места остановки
1. Начните урок и дойдите до 7-го задания из 20
2. Закройте вкладку браузера
3. Откройте приложение снова
4. Откройте тот же урок
5. **Ожидаемый результат:** Показано "📍 Вы на задании 7 из 20" ✅
6. Кнопка "Продолжить" вместо "Начать"
7. После нажатия "Продолжить" откроется 7-е задание

### Тест 9: Проверка краткости ответов ИИ
1. Начните выполнять упражнения
2. Введите правильный ответ
3. **Ожидаемый результат:** ИИ ответит кратко: "✅ Верно!" или "✅ Правильно!" ✅
4. НЕ должно быть длинных объяснений

### Тест 10: Проверка консоли (дебаг-информация)
1. Откройте консоль разработчика (F12)
2. При любых действиях вы должны видеть логи:
   - `🔄 Загрузка уроков из localStorage...`
   - `💾 Сохранено N уроков в localStorage`
   - `📖 Загружен прогресс урока #X`
   - `➕ Добавление урока #X`
   - `🗑️ Удаление урока #X`
3. Эти логи помогают отладить проблемы с сохранением

## 🚀 Запуск приложения

1. Убедитесь, что установлен Node.js
2. Установите зависимости:
```bash
npm install
```

3. Создайте файл `.env` в корне проекта:
```
GEMINI_API_KEY=your_api_key_here
```

4. Запустите приложение:
```bash
npm run dev
```

5. Откройте в браузере: `http://localhost:3000`

## 🔧 Решение проблем

### Проблема: Уроки не сохраняются
**Решение:**
1. Откройте консоль (F12)
2. Проверьте, есть ли ошибки
3. Проверьте, что localStorage доступен:
```javascript
localStorage.setItem('test', 'hello');
console.log(localStorage.getItem('test')); // Должно вывести: "hello"
localStorage.removeItem('test');
```
4. Если localStorage заблокирован, проверьте настройки браузера (cookies должны быть включены)

### Проблема: Данные пропали
**Решение:**
1. Проверьте console.log - там видно, загружаются ли данные
2. Проверьте localStorage вручную:
```javascript
// В консоли браузера
console.log(localStorage.getItem('german_lessons_v1'));
```
3. Если данные есть в localStorage но не загружаются - возможно ошибка парсинга JSON

### Проблема: ИИ не отвечает
**Решение:**
1. Проверьте, что API ключ Gemini правильно настроен в `.env`
2. Проверьте консоль на ошибки сети
3. Убедитесь, что используется правильная модель: `gemini-3-flash-preview`

## 📝 Структура localStorage

Приложение использует следующие ключи:

- `german_lessons_v1` - массив всех уроков
- `lesson_X_progress` - прогресс урока с ID=X (где X - это lesson_id)

Пример:
```javascript
// Посмотреть все уроки
JSON.parse(localStorage.getItem('german_lessons_v1'));

// Посмотреть прогресс урока #7
JSON.parse(localStorage.getItem('lesson_7_progress'));
```
